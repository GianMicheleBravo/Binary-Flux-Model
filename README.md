# Eclipsing-binary-model
A model to compute the flux of an eclipsing binary system at any time, at any wavelength. Optimized for speed and for offering a minimum number of free parameters, and suitable for detached systems without significant ellipsoidal stretching. 

Model assumptions:
- Both objects are spherical, opaque, and have an homogeneous surface.
- The binary orbit is circular
- Unless any other option is specified, both objects are modeled as blackbody emitters.
